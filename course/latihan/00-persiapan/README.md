# Latihan 00 — Lab Siap Pakai

**Modul:** [0 — Persiapan Lab](../../modul/00-persiapan-lab.md) · **Waktu:** 30 menit (setelah instalasi)

## Tugas

1. Jalankan skrip cek kesehatan:
   ```bash
   bash ~/robotika-tanpa-lab/course/kode/cek_lab.sh
   ```
2. Jalankan `talker` dan `listener` di dua terminal berdampingan.
3. Jalankan turtlesim + teleop dan gambar huruf pertama namamu dengan kura-kura.
4. Buka Gazebo dengan `gz sim shapes.sdf` dan tekan ▶.

## Yang dikumpulkan

Satu tangkapan layar yang memperlihatkan:
- hasil `cek_lab.sh` tanpa **[GAGAL]**, dan
- jendela turtlesim berisi huruf pertama namamu.

## Lulus jika

- [ ] `cek_lab.sh` menampilkan 0 gagal
- [ ] `listener` menerima pesan dari `talker`
- [ ] Turtlesim dan Gazebo bisa dibuka

Masih ada **[GAGAL]**? Cek tabel *Pemecahan masalah* di Modul 0, lalu tanyakan di forum
dengan menyertakan seluruh output `cek_lab.sh`.
